这是什么

把原来的「论文写作流水线 · 微信小程序 + Claude 后端」移植成的单文件网页工具。十阶段定义、状态机、断点续跑、每阶段的任务/验收标准/提示词组装逻辑与原版一致。

两种用法，二选一：
① 手工链（默认）：复制提示词 → 粘贴到任意 AI → 把产出回贴。零配置、零联网、任何设备可用。
② AI 直连（可选）：在「开题配置」里填 API 通道（端点 + Key + 模型），阶段页出现「⚡ 调用 AI 生成」，流式出字、可中止，产物直接落入回贴框。

与原版的差别：原版由后端直接调 Claude 模型跑完十个阶段；网页版没有后端，「调模型」这步要么你手工完成，要么用你自己的 Key 直连厂商。流程、顺序、验收全不变。

数据与隐私：流水线状态和 API Key 全部只存本机 localStorage，不上传任何服务器；Key 仅随请求发送到你填写的那一家厂商。已实测支持网页直连（CORS 放行）的厂商：DeepSeek / Kimi / 通义千问 / 豆包方舟 / 混元 / OpenAI，其余厂商以「测试连接」结果为准。
