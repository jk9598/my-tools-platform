能力与边界（实话版）

① 本工具是网页形态，跑在浏览器或容器 App 的 WebView 里：不能常驻后台，也无法直接读取其他 App 的屏幕，这是两个手机系统对网页的一致限制。
② 所以「读屏翻译」在这个形态下的落地方式是：译页（输入网址整页翻）+ 粘贴翻译（复制外文后点「粘贴」）。
③ 真正的「后台悬浮、自动读屏翻译」只有 Android 做得到：无障碍服务 + 悬浮窗。仓库附 android-float-translate/ 原生模块，可按其中 README 合并进容器 App；iOS 禁止任何应用后台读屏，只能走分享扩展。
④ 隐私：只有被翻译的文本会发往上方所选接口；设置与缓存只存本机 localStorage。
